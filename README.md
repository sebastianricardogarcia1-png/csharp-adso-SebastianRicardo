## Comparación de instrucciones en Python, JavaScript y C#

| Acción | Python | JavaScript | C# |
|---|---|---|---|
| Mostrar texto | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| Mostrar sin salto de línea | `print("Hola", end="")` | `process.stdout.write("Hola")` | `Console.Write("Hola");` |
| Leer un dato | `input()` | `prompt()` | `Console.ReadLine()` |
| Unir texto y variables | `f"Hola {nombre}"` | `` `Hola ${nombre}` `` | `$"Hola {nombre}"` |
| Crear una variable | `edad = 18` | `let edad = 18;` | `int edad = 18;` |
| Escribir un comentario | `# texto` | `// texto` | `// texto` |
